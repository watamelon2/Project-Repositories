# Plasma Probe Data Analysis

**UCLA Machine Learning for Physics · May–June 2025**

A five-person course project using Langmuir probe measurements from UCLA's Large Plasma Device to explore data-driven extrapolation of plasma conditions.

## Approach

The team prepared probe data with pandas and explored Gaussian mixture and random forest models. The project connects experimental data preparation with machine learning and scientific interpretation.
