## Reading the notebooks

Notebooks are being migrated from Google Colab. Saved figures and outputs will be retained where available. Some original input files are not yet included; the project pages describe these limitations. Saved outputs can be inspected without rerunning the analysis.

Project dates refer to when the work was completed, rather than when it was uploaded to this repository. Contributions to team projects and use of instructor-provided material are identified in the relevant project pages.

## Adding notebooks

Save each notebook in its project or coursework folder with a descriptive filename. For example:

- `projects/nuclear-physics/lab4_gamma_ray_analysis.ipynb`
- `projects/plasma-analysis/plasma_probe_analysis.ipynb`

Include a brief introductory Markdown cell explaining the question, approach, contribution, and current limitations. Update the materials column above as notebooks become available.
